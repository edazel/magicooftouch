# МАГИЯ КАСАНИЯ — сайт + Cloudflare + Telegram

Mobile-first сайт, заявочная запись, D1-хранилище, панель /api/admin, CSV для Excel, Telegram-уведомления и статусы. Дизайн-система и повествовательная подача вдохновлены современными spa-проектами из Awwwards (например, Goldust Spa и Antara Spa Wellness), без копирования чужих интерфейсов.

## Новые интерактивные элементы
- Дыхательный тренажёр с двумя ритмами, анимированным кругом, паузой/продолжением и счётчиком циклов.
- Интерактивный чек-ин по настроению с персональной подсказкой и карточки поддержки с генерацией/копированием фраз.
- Плавающая кнопка записи, появление блоков при прокрутке и подсветка карточек при наведении. Все эти фишки работают без API и сторонних библиотек.

## Что уже есть
- Услуги и подтверждённые цены: спина 40 минут / 2 600 ₽; всё тело 60 минут / 3 000 ₽. Добавлены три идеи ритуалов по запросу (30/50/75 минут) — стоимости пока не опубликованы и должны быть подтверждены Аней.
- Красивый адаптивный лендинг, заявки, подсказка свободных слотов (слоты заводятся в D1), мини-квиз, материалы, loyalty и два промокода.
- API принимает заявки, уведомляет admin-бота с кнопками подтвердить/отменить, синхронизирует клиентский бот по `/start <booking-id>`, панель редактирует статус/заметку и отправляет сообщение. Планировщик напоминает клиенту за сутки.
- В админке CSV выгружается с UTF-8 BOM и разделителями Excel.

## Развёртывание на Cloudflare
1. Создайте GitHub-репозиторий, загрузите файлы и подключите репозиторий в Cloudflare Workers & Pages. Развертывание Worker: `npx wrangler deploy` (или Git integration по конфигурации Wrangler).
2. Создайте D1: `npx wrangler d1 create magic-touch`. Подставьте `database_id` в `wrangler.toml`; затем `npx wrangler d1 execute magic-touch --remote --file=schema.sql`.
3. Добавьте секреты Worker: `npx wrangler secret put ADMIN_KEY`, `TG_ADMIN_TOKEN`, `TG_CLIENT_TOKEN`, `ADMIN_CHAT_ID`, `CLIENT_BOT_USERNAME`. Не кладите токены в GitHub. ADMIN_KEY — длинный случайный пароль.
4. Установите webhooks: `https://api.telegram.org/bot<TG_ADMIN_TOKEN>/setWebhook?url=https://ВАШ-ДОМЕН/api/telegram/admin` и аналогично для клиентского токена с `/api/telegram/client`. В BotFather создайте двух ботов. Узнайте собственный chat ID для ADMIN_CHAT_ID.
5. Для статического сайта GitHub Pages используйте этот Worker как API: в `app.js` замените `const API='/api'` на URL Worker, а CORS в `worker.js` ограничьте доменом сайта. Для одного домена предпочтительнее разместить assets и Worker вместе через Cloudflare Workers static assets. GitHub Pages сам по себе не запускает Worker — он обслуживает файлы, а API должен быть задеплоен отдельно.
6. Панель: `https://ВАШ-ДОМЕН/api/admin`; введите ADMIN_KEY. Для выгрузки используйте «Выгрузить Excel / CSV».

## Важные настройки перед запуском для клиентов
- Уточните точные часы работы и заранее заведите реальные свободные слоты таблицы `slots` (datetime в UTC/ISO). Публичный API показывает открытые даты; пока слоты не добавлены, заявка всё равно сохраняется, но время подтверждается лично.
- Разместите политику обработки персональных данных и согласие юриста/оператора. Форма сейчас явно собирает согласие, но публичную политику надо добавить до запуска.
- Добавьте точный район, адрес после подтверждения и рабочие правила отмены/переноса.
- Проверьте формат даты/часового пояса в D1; рекомендуемый формат слота — `2026-11-09T12:00:00Z`. В интерфейсе время показывается по часовому поясу устройства.
- Фото `hero.jpg` — специально сгенерированный артдирекшн для сайта; изображения и тексты из Telegram-канала автоматически не извлекались. При желании замените на свой логотип/реальные материалы с правами.

## Локальный просмотр
Откройте `index.html` или запустите `python3 -m http.server 8080`. Без задеплоенного Worker сайт показывает демонстрационные слоты и не принимает заявки — это ожидаемо.

## Промокоды и программа лояльности
`ПЕРВЫЙВЫДОХ` — приветственная скидка 10%; `КАСАНИЕ5` — задуманный бонус 15% после пятого визита. В этой версии промокоды сохраняются в заявке, но скидка не вычитается из платежа автоматически, а отметка визита пока вручную управляется оператором. До обещания автоматической скидки подключите валидацию и учёт посещений.

## Ограничения и безопасность
Функции панели защищены ADMIN_KEY. Добавьте rate limiting, ограничения CORS, captcha/антиспам и удаление данных по запросу до продакшена. Telegram-команды callback защищены сравнением admin chat ID. Если меняете домен, обновите URL Telegram webhook. Никакие токены не требуются для дизайна/локального просмотра.
