# МАГИЯ КАСАНИЯ — новый многостраничный сайт

Полностью новая версия: 5 самостоятельных страниц, единая визуальная система, оригинальные сгенерированные визуалы и предоставленный вами логотип. Mobile-first адаптивная вёрстка без сборщика и сторонних JS-библиотек.

## Страницы
- `index.html` — главная история бренда, визуальный первый экран, избранные услуги и приглашение к дыхательной паузе.
- `rituals.html` — описание подтверждённых массажей, цены, дополнительные пожелания без выдуманных услуг.
- `space.html` — страница Ани, домашнего камерного пространства и подхода.
- `pause.html` — отдельная страница с дыхательным тренажёром, практиками, чек-ином по настроению и карточками поддержки.
- `booking.html` — форма записи, свободные окна из API, выбор ритуала, промокод и Telegram-переход после отправки.

## Запуск и публикация
Это статические HTML/CSS/JS файлы плюс Cloudflare Worker API. Для одного домена (рекомендуется) загрузите содержимое папки в новый GitHub-репозиторий и разверните Worker на Cloudflare. GitHub Pages само по себе Worker не запускает.

1. Создайте D1 и установите ID в `wrangler.toml`:
   `npx wrangler d1 create magic-touch`
2. Примените схему:
   `npx wrangler d1 migrations apply magic-touch --remote`
3. Создайте Worker secrets (не размещайте их в GitHub):
   `npx wrangler secret put ADMIN_KEY`
   `npx wrangler secret put TG_ADMIN_TOKEN`
   `npx wrangler secret put TG_CLIENT_TOKEN`
   `npx wrangler secret put ADMIN_CHAT_ID`
   `npx wrangler secret put CLIENT_BOT_USERNAME`
4. Выполните `npx wrangler deploy` из папки репозитория. Папка assets настроена в Wrangler, Worker и сайт обслуживаются с одного origin.
5. Создайте двух Telegram-ботов через BotFather, задайте webhooks на опубликованный домен:
   - `https://api.telegram.org/bot<TG_ADMIN_TOKEN>/setWebhook?url=https://ВАШ-ДОМЕН/api/telegram/admin`
   - `https://api.telegram.org/bot<TG_CLIENT_TOKEN>/setWebhook?url=https://ВАШ-ДОМЕН/api/telegram/client`
6. Панель управления: `https://ВАШ-ДОМЕН/api/admin`, доступ по `ADMIN_KEY`.

## Перед публичным стартом
- Уточните тексты согласия/политики обработки персональных данных, добавьте документ на сайт.
- Добавьте реальные интервалы в таблицу `slots` (UTC ISO); пока слоты не заполнены, формы всё равно собирают желаемые дату и время, а подтверждение делает Аня.
- В ценах указаны только известные данные: спина 40 минут — 2 600 ₽; массаж всего тела 60 минут — 3 000 ₽. Новые длительности и цены не выдуманы.
- Промокоды пока сохраняются в заявке, автоматический расчёт скидки и автоматический учёт лояльности требуют отдельной логики.
- Перед запуском настройте rate limiting, CORS, защиту от спама и политику удаления персональных данных.
